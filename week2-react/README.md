# Online Store

A responsive online store built with React and Vite. The application fetches products from the DummyJSON API, displays them as product cards, and provides a separate details page for each product using dynamic routing.

## Features

- Fetch and display products from an external API
- Product-card layout
- Individual product details pages
- Dynamic routes based on product IDs
- React components
- Optimized rendering with React memoization
- Fast styling with Tailwind CSS

## Technologies Used

- React
- React Router DOM
- Tailwind CSS
- Vite
- JavaScript (ES6+)
- DummyJSON Products API
